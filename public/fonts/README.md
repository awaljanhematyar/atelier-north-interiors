# Local typefaces

Cormorant Garamond (headings) and Inter (body) are locally served Latin variable WOFF2 subsets, normal style, weights 400–600, with font-display: swap and system fallbacks. No runtime Google Fonts request is made.

Retrieved 2026-10-21 from the official Google Fonts CSS endpoint:
https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@400..600&family=Inter:wght@400..600&display=swap

- Cormorant Garamond: https://fonts.gstatic.com/s/cormorantgaramond/v21/co3bmX5slCNuHLi8bLeY9MK7whWMhyjYqXtK.woff2
- Inter: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2

SIL Open Font License copies are included for both families, obtained from their official Google Fonts source directories:
https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
https://github.com/google/fonts/tree/main/ofl/inter

These subsets support the current English demo. Additional language coverage must be checked before localization.
