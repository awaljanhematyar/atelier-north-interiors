## Local asset recipe

Each ID has two locally hosted files: `{id}-640.webp` and `{id}-1600.webp`. Downloads used Pexels' image CDN resizing/compression, preserving the full image at each width:

`https://images.pexels.com/photos/{id}/pexels-photo-{id}.jpeg?auto=compress&cs=tinysrgb&w={width}&fm=webp`

The browser selects a variant through srcSet and sizes. CSS object-fit crops images for editorial frames; original aspect ratios are retained in the local files. Hero images load eagerly; supporting images load lazily. The shared Photo component displays an accessible text fallback if loading fails. Descriptive alternative text is maintained with each image record in src/data/projects.js. No external image request is needed at runtime.

Review source availability and licence terms before adding or replacing photography. Avoid visible personal information, prominent third-party marks or uses implying endorsement. This record describes the checked licence, not ownership of the photographed spaces or a guarantee of unrelated property rights.
